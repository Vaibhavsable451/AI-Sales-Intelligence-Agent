Architecture

Six phases, twenty-eight nodes

Every step is a real node in the n8n workflow — nothing here is simplified for the diagram.

01 / intake
Receive & normalize
1. Webhook – Receive URL 2. Set – Normalize Input
02 / scrape
Fetch & extract, in parallel
3. HTTP – Fetch Website HTML 4. Extract – Title & Meta 5. Extract – Body Text 6. Extract – Tech Signals 7. Code – Clean & Merge
03 / enrich
External company research
8. HTTP – SerpAPI Company Search 9. Code – Parse Results 10. Merge – Scrape + Search
04 / reason
Three LLM agents, run on Groq (Llama 3.3 70B)
11. Agent – Pain Point Analysis 12. Code – Parse Pain Points 13. Agent – Company Research 14. Code – Parse Research 15. Merge – Aggregate Outputs 16. Agent – Personalization
05 / compose
Draft, validate, build the report
17. Code – Parse Pitch 18. Agent – Sales Copywriter 19. Code – Parse Final Copy 20. IF – Validate Output 23. Code – Build Final HTML Report
06 / deliver
Three channels, fired in parallel
24. Gmail – Send Draft 25. Sheets – Log Lead 26. Slack – Notify Team 27. Set – Format Response 28. Respond to Webhook
